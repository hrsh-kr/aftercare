    Run it yourself, and say anything.

    The recording can only replay what was recorded. The real thing is one Lambda behind API Gateway on SAM Local, with OpenSearch, DynamoDB Local, Cedar and a local model. It runs on your machine: load an order file, message as any customer and type whatever you like.

    python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
bash scripts/install_cedar_cli.sh
ollama serve            # another terminal
bash scripts/dev.sh     # then open http://127.0.0.1:3000/sandbox

    Needs Docker, the AWS SAM CLI and Ollama. Click-by-click script: docs/SANDBOX_RUNBOOK.md. Design: docs/ARCHITECTURE.md. No AWS account is used and nothing is deployed to AWS (Build It track).

    Recorded by scripts/record_playback.py through the same Meta-shaped webhook and staff endpoints the real sandbox uses. Only the persona blurbs are hand-written. What you see is a playback, so it cannot answer anything that was not recorded.
