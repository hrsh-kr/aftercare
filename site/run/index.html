AAftercare Recorded run

Run it yourself.

This site is a static copy: the story, a recorded run of the sandbox, and a dashboard snapshot. The real thing is one Lambda behind API Gateway on SAM Local, with OpenSearch, DynamoDB Local, Cedar and a local model, so it runs on your machine, not on a static host.

You need

  • Docker running, the AWS SAM CLI, Python 3.12+, and Ollama (the model, gemma2:9b, is pulled for you)
  • About 10 GB of disk and 16 GB of RAM to be comfortable

Five commands

python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
bash scripts/install_cedar_cli.sh
ollama serve            # in another terminal
bash scripts/dev.sh     # containers, tables, sam build, sam local start-api
# open http://127.0.0.1:3000/sandbox

The click-by-click script for all eight customers is docs/SANDBOX_RUNBOOK.md in the repository; the design is docs/ARCHITECTURE.md.

What is real, what is not

Real: the order-file check and customer registry, the agent, manual search, tickets, the message log and inbox where a person replies, Cedar policies, DynamoDB and the Lambda. Simulated: WhatsApp's network. The customers, orders and manuals are fabricated. Nothing is deployed to AWS and no AWS account is used (Build It track).
